# Local web fonts

This folder contains the two self-hosted fonts used by the site brand layer.

- `qiji.woff2`: QIJI by Lingdong Huang, used only for the homepage Chinese manifesto.
- `chill-longcang-medium.woff2`: Chill Calligraphy LongCang Medium, used for Chinese navigation, introductions and section headings.

Both fonts are distributed under the SIL Open Font License 1.1. The corresponding license notices are included in this folder.

Project cards and project information deliberately keep the original website typography.
